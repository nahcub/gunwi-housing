## 4. 방법론 요점 (상세는 `docs/methodology.md`)

- **고령화율** = 65세+/총인구. 주민등록(외국인 제외, 거주불명자 포함).
- **인구 변화율** = (P₂₀₂₆₋₀₉−P₂₀₂₃₋₁₂)/P₂₀₂₃₋₁₂, 연평균 = (P1/P0)^(12/33)−1. 12월↔9월 계절차는 검증 안 함.
- **리별 인구**: 법정동별 CSV(1세 단위, 0~110세+). 읍면 합 = 행정동 주민등록(8개 읍면·두 시점·65세+ 모두 일치, prepare 에서 assert).
  2023-12 판엔 리 미지정 삼국유사면 1명 행 → 리별에서 제외, 읍면 합엔 포함.
- **노후주택**: 대상 = 건물통합정보 용도 '단독주택'·'공동주택' 10,264동(용도 빈칸 38,743동은 집인지 알 수 없어 제외).
  기준일 = 분석 시점 말일 − 30년(1996-09-30). 군: 확인 27.5% / 추정 포함 61.3% / 빈칸 34.3%. 1900년 이전 사용승인 69동은 그대로 노후.
- **집별 거리**: 주거용 건물 중심점(EPSG:5186) → `STRtree.query_nearest`. 리 배정은 건물 법정동코드(좌표 판정과 11동 차이).
- **시설 리 배정**(`assign_facilities`): 좌표→리 경계 포함(경계선 위는 코드 작은 쪽), 상가→원자료 법정동코드(좌표와 9/1,155 차이: 대형 건물 공유 좌표),
  폐교→주소 '읍면 리' 이름(고로면→삼국유사면). 대조: 경로당 215/215·HIRA 42/42·학교 8/8 일치.
- **좌표 보정 1건**(`HIRA_COORD_FIXES`): HIRA 가 대율보건진료소를 부계면보건지소(창평리) 좌표로 넣음 → 보건복지부 목록 주소
  (한티로 2146-1, 대율리) + 건물통합정보 같은 이름 건물(673-2, 756 중 연면적 큰 쪽). 이 보정으로 부계면 1차의료 평균 3.8→1.5km.
- **노령화지수 등**: 65+/0~14×100, 노년부양비 65+/15~64×100, 평균나이 Σ(나이×인원)/인구(110+는 110), 밀도 = 인구/리 면적 합.
- **빈집률·종합점수 안 만듦**(§2·§3). 출처가 다른 빈집 수·주택 수를 섞거나 서로의 분모로 쓰지 않는다.
- 학교 해석: 거점학교 정책·통학버스로 "가장 가까운 학교 ≠ 다니는 학교". 운영 고교는 군위고 1곳.

| `kindergarten-general-2026-2` / `closed-schools-2025-09-30` | 유치원 1 / 폐교 11 | `ri_facilities.json` 개수만 |
| `datagokr-gunwi-senior-2025-12-19` | 경로당 215 (포털 원본과 바이트 일치, 연간 갱신 차기 2026-12-19) | `senior_centers.json` |
| `binzibe-gunwi-vacant-houses-2025` | 빈집애 읍면 빈집 수(내부 API 응답) | `vacant_houses.json` |

- 50MB 넘는 전국 원본(상가 zip, 브이월드 리 경계 zip, 건물통합정보 대구 zip)은 **앞 세션 PC 의 `~/Downloads/gunwi-dl/` 에만 있다**.
  다음 작업자 PC 엔 없다. sha256 은 각 `_meta.json` 에 있으니 같은 판을 다시 받아 대조하면 된다(브이월드는 로그인 필요).
- 추출 방식: CSV 는 원본 줄 바이트 그대로, SHP/DBF 는 레코드 바이트 복사(헤더·SHX 만 재작성). pyshp 로 다시 쓰면 DBF 소수 값이
  바뀐다(실제로 424건 발생해 방식을 바꿨다).
- 출처 등록은 항상 `tools/add_source.py` (sha256·_meta.json 자동). 상태·사유는 `data/sources.json`.

## 6. 코드 지도

```
tools/prepare.py      population(+세대) / boundary / senior_centers / vacant_houses → prepare_ri 호출
tools/prepare_ri.py   prepare_ri_boundary · assign_facilities(+HIRA_COORD_FIXES, GROCERY_EXCLUDE)
                      · prepare_access(ACCESS_GROUPS, ACCESS_FAR_M) · prepare_housing_age(OLD_HOUSE_YEARS,
                      TRADITIONAL_STRUCTURES) · prepare_ri_population(노령화지수·밀도 포함)
tools/build.py        INDICATORS(units) · build_regions(읍면 행 + ri) · build_ri_rows · 공개 결정
tools/export_excel.py COLUMNS(읍면) · HOUSING_COLUMNS · RI_COLUMNS(리별지표 시트·CSV)
tools/figures.py      그림1 읍면 지도 4장, 그림2 지표 순위상관(읍면 8개)
public/app.js         읍면↔리 전환(setUnit, buildAreaLayer), 지표 목록은 units 로 거름
```

- 새 지표 추가 순서: prepare(_ri) 에서 derived 에 값 → `build.py` INDICATORS(+units) 와 행 필드 → 리면 `RI_POPULATION_FIELDS`/
  `_housing_access_fields` 와 테스트 허용 필드(`test_ri_rows_are_aggregates_only`) → `export_excel.py` 열 → `app.js` 상세 → methodology.
- 실행: `python tools/prepare.py && python tools/build.py && python tools/export_excel.py && python tools/figures.py && python -m pytest -q tools/tests`.
  미리보기: `python -m http.server 8791 --directory public` (앞 세션은 `gunwi/.claude/launch.json` 의 `gunwi-housing-map`).
- 의존성: `pyshp==3.1.6 pyproj==3.8.0 shapely==2.2.0` 고정(derived 바이트 재현). 좌표·거리는 반올림해 플랫폼 차이를 흡수.
- CI(`deploy.yml`): main push 때 prepare 재실행 → `git diff --exit-code data/derived/` → pytest → build. Cloudflare 키가 없어 배포는 건너뜀.
  **derived 를 손으로 고치거나 prepare 에 실행 날짜를 넣으면 CI 가 깨진다.**

## 7. 알려진 문제·한계 (보고서에 쓸 것 포함)

- 리별 빈집 없음(선임 답변 대기). 빈집은 읍면 8개 값뿐이라 리 단위 도출에서 빈집 축이 빈다.
- 거리는 직선. 버스 운행 횟수 없음. 집 = 건물(사람 수 아님, 빈집 포함). 대장 미연계 건물(용도 빈칸)은 빠짐.
- 노후 추정은 빈칸 비율이 높은 리(최대 76%)에서 추정 의존도가 크다 → 확인분·빈칸 비율을 함께 제시.
- 소인구 리의 비율 변동, 노령화지수 리 단위 정의 불가(18곳).
- 경로당 2025-12, 빈집애 2025 — 분석 시점보다 이르지만 받을 수 있는 최신판.
- 그림2(상관표)가 지표 20여 개로 너무 크다. 읍면 8개라 상관 해석도 약하다 — 보고서용으로 줄일 필요.
- 웹: 브라우저 창이 숨겨진 상태에서 처음 열면 Leaflet 이 `Invalid LatLng (NaN, NaN)` 를 낸다(지도 크기 0 에서 fitBounds).
  보이는 상태에선 정상. 고치려면 지도 크기가 잡힌 뒤 `invalidateSize()`/`fitBounds` 를 다시 부르면 된다.
- 유치원·폐교는 리별 개수만 있고 거리 지표는 없다(폐교는 좌표 없음).

## 8. 다음 작업자를 위한 메모

**도출 방법을 정할 때** — 리 단위로 바로 쓸 수 있는 축: 노후(old_house_ratio), 인구감소(pop_change_rate),
고령화(elderly_ratio·old_dependency), 접근성(primary_care·grocery·school·childcare·bus). 빈집은 읍면만.
- 척도가 다르다(%, m, 명). 결합하려면 표준화·순위·임계값 중 하나를 고르고 근거를 `docs/methodology.md` §3 에 먼저 적는다.
  가중합 점수를 만들면 CLAUDE.md "종합 점수는 계산하지 않는다"와 테스트(`priority_score` blocked)를 같이 고쳐야 한다 — 이건 의도적 장치다.
- 사업별로 보는 축이 다를 수 있다(예: 빈집 정비 = 빈집·노후 / 귀농·귀촌 거점 = 접근성 양호 + 빈집 / 마을재생 = 인구감소·고령화).
  어디까지나 예시이며 앞 세션에서 정하지 않았다.
- 과거 사업지(중복 검토용, 언론 확인·raw 미등록): 새뜰마을 2015~19 우보 모산·문덕1, 의흥 지호3·연계2, 효령 화계3 /
  창조지역사업(2015 기사) 고로(삼국유사) 화북·석산, 산성 화본, 부계 대율 / 군위읍 농촌중심지활성화 2020~25. 출처는 `docs/data-survey.md` §5-3.
- 소인구 리는 순위에서 인구 수를 함께 보거나 최소 인구 기준을 두는 것을 고려.

**보고서를 쓸 때** — 지표 정의·근거·한계는 `docs/methodology.md`, 출처·기준일은 엑셀 `산출방법`·`컬럼설명` 시트,

**작업 습관(앞 세션에서 굳어진 것)**
- 숫자는 원자료에서 직접 센 것만 쓴다. 보도자료 숫자는 문서에 "원자료 아님"으로만 언급.
- 외부 조사(서브에이전트 포함) 결과는 핵심 숫자를 받은 파일로 다시 세어 확인한 뒤 반영했다.
- 사용자에게 줄 복사용 문안은 코드 블록에 넣고 번호는 "1)" 형식(마크다운 목록 번호는 복사 시 사라짐).
- Windows: `PYTHONIOENCODING=utf-8` 필요. 다운로드 파일을 여는 임시 스크립트는 scratch 폴더에 두고 `python -I` 로 실행
  (단 `-I` 는 사용자 site-packages 를 막아 openpyxl·pyshp 를 못 찾음).
- 커밋은 브랜치에서, 커밋 메시지 끝에 `Co-Authored-By` 줄. derived 는 코드 변경과 같은 커밋으로.
