# 정보공개청구 초안

**발송하지 않았다.** 초안만 둔다. 발송·접수는 사람이 한다.
청구는 정보공개포털(https://www.open.go.kr) 또는 군위군청 정보공개 담당부서를 통해 제출한다.
개인정보(성명·연락처·상세주소)는 수령·보관·공개 저장소 업로드에서 제외한다.

대상 기관: 대구광역시 군위군청 (담당: 인허가과, 2026-10-30 조사 기준)
(2023-07-01자로 경상북도 군위군 → 대구광역시 군위군으로 편입)

이전 주제(민원·시설관리)의 청구 초안 4건은 git 커밋 `ea23c30` 의 이 파일에 있다.

## 1. 빈집 실태조사 결과 (비식별) — `GUNWI_VACANT_SURVEY_INTERNAL`

> 군위군 관내 빈집·노후주택 주거환경 분석 연구를 위해 아래 정보의 공개를 청구합니다.
>
> - 대상 자료: 군위군이 실시한 빈집 실태조사 결과 (가장 최근 조사분, 이전 조사분이 있으면 함께)
> - 요청 항목(비식별): 조사연도·조사기준일, 읍·면, 리, 빈집 등급(조사에서 쓴 구분 그대로),
>   주택 유형, 건축연도(조사 항목에 있는 경우)
> - 건별 제공이 어려우면 **읍·면·리별, 등급별 빈집 수 집계표**로도 충분합니다
> - 등급을 판정한 기준(조사 지침 또는 기준표)이 있으면 함께 제공해 주십시오
> - **개인정보(소유자 성명·연락처, 상세 지번·도로명주소)는 제공하지 않아도 됩니다**
> - 형식: CSV/XLSX 등 전자파일
>
> 공개 시 개인정보가 포함되지 않도록 비식별 처리해 주시기 바랍니다.

받으면: `docs/how-to.md` §8 절차로 등록한다. 지번 등 개인 식별 가능 정보가 섞여 있으면
공개 저장소에 올리지 않고 비식별 집계만 raw 에 둔다.
