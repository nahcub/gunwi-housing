# 군위군 빈집·노후주택 자료 조사 (data-survey)

조사일: 2026-10-30. 이전 주제(생활불편 민원)의 조사 기록은 git 커밋 `ea23c30` 의
같은 파일에 있다.

## 0. 표기 규칙

- **데이터를 만들지 않는다.** 샘플값·추정값·보간값은 쓰지 않는다. 없으면 "미확보".
- 숫자는 저장소 raw 나 조사 때 내려받은 파일에서 직접 확인한 것만 적는다.
  파일로 확인하지 못한 숫자(보도자료·화면에서 본 값 등)는 적지 않는다.
- 확인하지 못한 URL·데이터셋 번호는 추측해서 적지 않는다.
- 상태는 `data/sources.json` 의 `status` 와 같게 쓴다: `확보` / `미확보`.

### 조사 때 내려받은 파일에서 확인한 것

저장소 raw 가 아니라 조사용으로 받아 본 파일에서 확인한 값이다. 쓰려면 §3 절차로 등록한다.

- KOSIS DT_1JU1512 2025년 파일: 군위군(코드 22520) 미거주주택 계 1,355호, 그중
  1979년 이전 건축 1,060호. 단독주택 1,160 · 아파트 73 · 연립 35 · 다세대 62 · 비주거용 건물 내 주택 25.
  작은 칸은 `X` 로 비공개.
- 주택보급률(15107492): 군 단위 7행(2019~2025).
- 병의원·약국(15051059, 2026-09): 주소에 군위군이 들어간 행이 병원정보 35, 약국정보 7.
- 시가표준액(15080040): 12,672행, 법정동·법정리·본번·부번 열이 있다.
- 상가정보(15083033): zip 안 파일명이 201812 로 표기돼 있어 기준일을 다시 확인해야 한다.

### 빈집 수가 출처마다 다른 이유

- 빈집애: 지자체 빈집행정조사(읍면별 수만 공개)
- 통계청 미거주주택: 인구주택총조사 등록센서스 기준, 시군구 단위
- 군청 빈집 실태조사: 결과 파일을 확보하지 못해 수를 적지 않는다

정의와 조사 방법이 달라 값이 다르다. 한 산식에서 섞지 않는다. 같은 정의의 분모가 없어
빈집률은 계산하지 않는다(`docs/methodology.md` §2).

## 3. 다음에 할 일

1. **건축물대장 수집기 작성** — `DATA_GO_KR_KEY` 환경변수로만 키를 읽는다. 받은 응답은
   `tools/add_source.py` 로 새 raw 폴더에 등록한다.
2. **군청 정보공개청구** — 빈집 실태조사 결과(등급·리별 수). 초안 `docs/requests/README.md` (미발송).
3. **SGIS 건축년도별주택 연결** — 코드집으로 항목코드–연도 구간을 확인한 뒤 `prepare.py` 에 연결.
4. 위 §2 의 파일 다운로드 자료는 필요한 것만 §3(how-to) 절차로 등록한다.

## 4. 보안·개인정보 주의

- 빈집 실태조사 결과에 소유자·상세 지번 등 개인정보가 있으면 **public 저장소에 올리지 않는다.**
  비식별 집계(읍면·리별 수, 등급별 수)만 raw 에 둔다.
- API 인증키는 `DATA_GO_KR_KEY` 환경변수에서만 읽는다. 코드·파일·로그·커밋에 적지 않는다.
