# 지표 산식과 근거

원칙: **공식 기준과 프로젝트 파생지표를 구분한다.** 근거 없는 합성 지표는
계산하지 않는다. 산식을 바꿀 때는 코드만 고치지 말고 이 문서를 함께 고친다.

## 1. 지금 계산하는 것

### 고령화율

```
고령화율(%) = 65세 이상 인구 / 총인구 × 100
```

출처: 행정안전부 주민등록 인구통계, 5세 연령구간의 65세 이상 8개 구간(65~69 …
100세 이상) 합.

주의 — 이 값은 **주민등록 기준**이다. SGIS 격자 통계나 센서스의 고령인구와
모집단이 다르므로 섞어 쓰지 않는다. 외국인은 제외되고 거주불명자·재외국민은
포함된다.

`tools/prepare.py` 가 구간 합계 = 총계, 남+여 = 계, 읍면 합계 = 군 합계를
모두 검증한 뒤에만 이 값을 만든다.

### 인구 변화 (2026-11-05 추가)

분석은 한 시점(`ANALYSIS_PERIOD` = 2026-09) 진단이다. 인구 시계열(2023-07~2026-09 매월)은
raw 에 두고, 분석 시점 값으로는 기준 시점(`BASELINE_PERIOD` = 2023-12) 대비 변화만 낸다.

```
인구 변화율(%)        = (P_2026-09 − P_2023-12) / P_2023-12 × 100
연평균 인구 변화율(%/년) = ((P_2026-09 / P_2023-12)^(12 / 33) − 1) × 100     (33 = 개월 수)
고령화율 변화(%p)      = 고령화율_2026-09 − 고령화율_2023-12
```

- 출처: 행정안전부 주민등록 인구(두 시점 모두 같은 출처·같은 검증). 산식은 `tools/build.py`
  `build_regions()` 한 곳에만 있고 엑셀은 그 값을 가져다 쓴다.
- 기준 시점을 2023-12 로 둔 이유: 대구 편입(2023-07) 뒤 첫 연말이고, 리 단위 출발값(연보 제64회,
  정보공개청구 요청 기준일)과 같은 시점이다. 이전 시점은 분석 범위 밖이다.
- 기간이 2년 9개월이라 1년 단위가 아니다. 읍면끼리 비교에는 변화율이나 연평균 변화율 어느 쪽을
  써도 순위가 같다. 연평균은 다른 기간의 자료와 견줄 때만 쓴다.
- 연말(12월)과 9월은 계절이 다르다. 주민등록 인구의 월별 계절 변동이 작다는 확인은 아직 안 했다.
- 군 전체: 22,988 → 22,432명(−2.4%, 연 −0.88%), 고령화율 44.9% → 50.5%(+5.6%p).

|---|---|---|---|

- 경로당 "노후" 2000년 기준은 근거 문서가 없다. 확정되면 상수 하나만 바꾼다

  (인구밀도는 SGIS 인구 기준)

### 리 단위 배정 (2026-11-05 추가)

리 단위 공간단위는 **법정리 92개**(브이월드 법정구역정보 2026-10-09)다. 행정리(2023 180개,
2025-01-01 182개) 경계는 공개 자료가 없어 쓰지 않는다. 행정리 단위 자료(연보 리별 인구,
정보공개청구 결과)는 행정리명에서 번호를 뗀 법정리로 합쳐 쓴다 — 이름 규칙에 기댄 추정이므로
쓸 때 그 사실을 밝힌다.

시설 배정 규칙(`tools/prepare_ri.py`):

### 집별 생활시설 거리 (2026-11-05 추가)

리 대표점 하나로 재면 리 크기(지름 중앙값 2.8 km) 때문에 오차가 비교 대상과 비슷해진다.
그래서 **집마다** 잰다.

```
집      = GIS건물통합정보(2026-09-09) 용도 '단독주택'·'공동주택' 건물 10,264동의 중심점
거리    = 집에서 가장 가까운 시설까지 직선거리(m), EPSG:5186 평면
리 값   = 그 리 집들의 평균·중앙값·최댓값, ACCESS_FAR_M(2,000 m, 모든 묶음 공통) 초과 집 비율
```

2026-11-06 버스·학교·어린이집·식료품점을 추가했다. '먼 집' 기준은 **모든 묶음에 같은 2,000 m** 로
정했다(2026-11-06 사용자 확인). 법정 기준이 아닌 프로젝트 기준이다. 버스정류장은 거의 모든 집이
2 km 안이라(군 0.9%) 이 기준으로는 변별력이 없다 — 버스는 평균 거리로 본다.

- **버스 '(미정차)' 제외**: 군위IC·서군위IC·동군위IC·군위JC 의 '(미정차)' 행(방향별 2행씩 8행)은
  고속도로 IC·JC 지점이라 버스가 서지 않는다. 집 근처에 있으면 거리가 짧게 잡혀 왜곡되므로 뺀다.
  같은 정류장이 여러 BIS(대구·칠곡·구미·영천 등)에 중복 등록된 것은 가장 가까운 거리에는 영향이
  없어 묶지 않는다.
- **버스 거리 ≠ 서비스 수준**: 정류장 자료에는 노선·운행 횟수가 없다. 하루 몇 번만 서는 정류장도
  가까우면 거리가 짧게 나온다. 정류장까지 거리는 '버스를 탈 수 있는 정도'가 아니라 '정류장이
  있는가'만 말한다.
- **학교**: 원자료 운영상태 '운영' 8곳(초 4: 대구군위초·대구부계초와 고매·의흥 캠퍼스 / 중·고 4:
  군위중·부계중과 효령캠퍼스·군위고)을 쓴다. 2026-11-06 언론 보도로 대조한 결과 2026학년도에 학생이

  (15015254) 15곳에는 휴교한 효령고(2021~, 재학생 0)·우보초·송원·석산·효령(초) 캠퍼스·의흥중·
  군위중 우보캠퍼스가 들어 있어 쓰지 않는다. 부계중 효령캠퍼스의 2026 재학생 수는 확인하지 못했다.

  15곳을 뺀 60곳(`GROCERY_EXCLUDE`, 상가업소번호로 고정). 2026-11-06 '휴게소' 키워드로 3곳을 1차로
  거르고, 상호를 보고 휴게 시설 2·캠핑장·관광지 5·매점·주유소 4·분류 오류 1(원자료 업종 숙박업)을

- **읍면사무소**: 좌표 자료가 없어 거리 묶음에 넣지 않는다(2026-11-06 사용자 결정).

- 리 배정은 건물의 법정동코드(지번). 중심점 좌표 판정과 다른 집 11동.

### 노후주택 (2026-11-05 추가)

```
대상       = GIS건물통합정보 주거용 건물(단독·공동주택) 10,264동, 분모는 전체(빈칸 포함)
노후(확인) = 사용승인일 ≤ 분석 시점 말일 − 30년 (2026-09 → 1996-09-30)
노후(추정) = 사용승인일 빈칸 + 구조가 목·조적·블록·벽돌·석조 (TRADITIONAL_STRUCTURES)
주 지표    = (확인 + 추정) / 전체.  하한 = 확인 / 전체.  추정 의존도 = 빈칸 / 전체
```

- **사용승인일**: 완공 후 관청이 사용을 승인한 날(건축물대장). 집 나이의 기준.
- **빈칸 처리 근거**: 빈칸 3,522동의 98% 가 재래식 구조·1층·소형(연면적 중앙 58㎡)이다. 사용승인 제도
  (1962 건축법) 이전에 지어 소급 등재된 옛집으로 본다. 30년 미만으로 확인된 집에는 목조 5%·조적류 32%
  뿐이다. 빈칸 비율이 읍면별로 2%(부계)~54%(산성)로 기록 관행에 따라 달라, 빈칸을 빼면 빈칸이 많은
  읍면이 새 집이 많은 곳처럼 왜곡된다.
- 30년은 법정 기준이 아니다(도시정비법 노후·불량 건축물은 조례로 20~30년). 국토부 건축물 통계의
  흔한 구분을 따른 프로젝트 기준이다.
- 사용승인일 1900년 이전 69동(1820년대 등)은 그대로 노후로 센다(확인은 안 했다).
- 군 전체: 확인 27.5%, 추정 포함 **61.3%**, 빈칸 34.3%.

## 2. 계산하지 않는 것: 빈집률

빈집애 읍면별 빈집 수(합 602)는 raw 에 있지만 **빈집률은 만들지 않는다.**

- 빈집애 수는 지자체 빈집행정조사 결과다. 같은 조사에서 나온 전체 주택 수(분모)가 없다
- SGIS 주택 수(`to_ho_001`, 2024)나 통계청 미거주주택(등록센서스)은 조사 방법·정의가
  다르다. 서로 다른 출처를 분자·분모로 나누면 비율의 의미가 없다
- 빈집애의 `binzipRateReg` 는 빈집률이 아니라 군 전체 빈집 수 대비 그 읍면의 비중이다

같은 정의의 분모가 확보되면 산식과 출처를 이 절에 먼저 적고 계산한다.
빈집 수 자체를 비교할 때도 출처를 섞지 않는다(빈집애 602, 통계청 미거주주택은 군 단위 별도 값).

노후주택(건축연도) 지표도 아직 계산하지 않는다. SGIS 건축년도별주택은 raw 에 있으나
항목코드–연도 구간 대응을 코드집으로 확인하기 전이고, 건축물대장은 미수집이다.
"노후" 기준 연도를 정할 때는 근거 문서를 이 절에 적는다.

## 3. 계산하지 않는 것: 종합 점수

여러 지표를 가중합한 종합 점수나 취약순위는 **산출하지 않는다.**

1. **공식 산식이 없다.** 주거환경 취약을 하나의 숫자로 합치는 승인된 가중치가 없다.
2. **척도가 다르다.** 건수·비율·지수를 표준화 없이 더하면 숫자의 의미가 사라진다.
3. **검증할 수단이 없다.** 가중치가 맞는지 대조할 결과 자료가 없다.

`public/data/regions.json` 의 `priority_score` 는 `status: "blocked"` 이고
값이 존재하지 않는다. `tools/tests/test_build.py` 가 값이 채워지는 것을 막는다.
엑셀의 `종합점수` 열도 비워 둔다.

근거(표준화 방법, 가중치 근거와 합의 주체, 민감도 분석)를 이 문서에 기록하기 전에는
상태를 바꾸지 않고, 미확보 항목을 0으로 채우지 않는다.

## 4. 결합할 때 주의

- **기준시점 통일** — 파일 수정일과 데이터 기준시점은 다른 개념이다.
  `_meta.json` 이 `retrieved_at` 과 `reference_date` 를 따로 기록하는 이유다
- **행정구역 변동** — 군위군은 2023년 경북 → 대구 편입. 이전 자료는 옛 명칭·
  코드를 쓰므로 검색·결합 시 대응표가 필요하다
- **코드 체계** — 주민등록 행정기관코드와 SGIS 행정동 코드는 다른 체계다
  (`CLAUDE.md` 참고). 빈집애 API 는 통계청 코드(27720)를 쓴다
- **비공개값** — 통계 비공개 처리된 값(`N/A`, `X`)을 0으로 변환하지 않는다
- **범례** — 현재 코로플레스 구간은 화면에 보이는 8개 값의 상대 척도다.
  절대 기준이 아니므로 시점 간 색을 직접 비교하지 않는다
- **지표 간 상관** — 그림2(Spearman 순위상관)는 같은 현상을 중복으로 재는 지표를 찾는
  용도다. 읍면 8개라 n=8 의 양측 5% 임계값은 |ρ| ≥ 0.738 이다
